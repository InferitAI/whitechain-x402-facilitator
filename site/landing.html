Whitechain x402 Facilitator

This server is a public x402 facilitator for Whitechain, WhiteBIT's EVM L2. Point any standard x402 resource server at it and AI agents can pay your API per request. Payments go straight from the payer to your address; this service verifies the signature, submits the transfer and pays the gas. It never holds funds.

  • Schemeexact (EIP-3009)
  • Networkeip155:1874, testnet
  • PriceFree, rate-limited
  • CustodyNone
Documentation Source on GitHub

Endpoints

GET /supportedSchemes, networks and the facilitator's signer addresses.
POST /verifyVerify an x402 v2 paymentPayload against paymentRequirements.
POST /settleSubmit the signed authorization on chain; returns the transaction hash.
GET /healthStatus, gas balance of the facilitator wallet and settlement runway.
GET /metricsJSON counters: verifies, settles, failures by reason, gas spent.

Use it from your API

Set this server's base URL as the facilitator in @x402/express, @x402/hono or @x402/next, and price your route in an EIP-3009 token on eip155:1874:

const facilitator = new HTTPFacilitatorClient({ url: "<this server's base URL>" });
const server = new x402ResourceServer(facilitator).register("eip155:1874", new ExactEvmScheme());

app.use(paymentMiddleware({
  "GET /weather": {
    accepts: {
      scheme: "exact",
      network: "eip155:1874",
      payTo: "0xYourMerchantAddress",
      price: { asset: "0x2E672dFE33EA977FD064E01aDe7d8c73B3Be7fBB", amount: "10000",
               extra: { name: "Inferit Test Credit", version: "1" } },
    },
  },
}, server));

Agents pay with @x402/fetch and ExactEvmScheme; they need the token, not WBT. The full quickstart, the API reference and self-hosting instructions are in the documentation.

Testnet policy. Settlement gas is sponsored within per-IP, per-payer and per-merchant rate limits and a daily gas budget. Addresses on the sanctions denylist are refused. Signatures are never logged. Testnet tokens have no value.
